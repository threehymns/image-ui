# Triage Labels

The repository uses the canonical five-role triage labels:

- `needs-triage`: A new issue awaiting categorization and scoping.
- `needs-info`: Blocked on additional information or clarification.
- `ready-for-agent`: Fully specified and ready for autonomous agent implementation.
- `ready-for-human`: Requires human review, judgment, or manual verification.
- `wontfix`: Decided out of scope or rejected.
